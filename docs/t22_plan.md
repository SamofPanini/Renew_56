# T22 分析计划（在读取 2010 年迁移数据之前提交）

来源：Notion 任务单 T22「V-08 对照：2010 年普查五年迁移表复跑引力模型」。提交日期：2026-11-24。之后如需偏离，必须在报告里单列“与计划的偏离”。

## 要回答的问题

把 T20 的同一套模型原样搬到 2005→2010 的迁移上，看“同一方言区”“同一经济大区”“相邻”的系数方向与离差下降比例是否和 2015→2020 相近。这是**对照，不是趋势分析**：不合并两年做面板，不下趋势结论。

## 沿用 T20 的全部设定（见 `docs/t20_plan.md`、`docs/t20_report.md`）

- 观测单位：有向省对 (i→j)，i≠j，930 个。结果变量：五年前常住 i 省、现住 j 省的人数。
- 估计：泊松伪极大似然（PPML），迁出省、迁入省固定效应，省会间球面距离的对数；稳健标准误 HC1。
- 模型：M0 基线；M1 相邻；M2 同一经济大区；M3 同一方言区；M4 同为官话或同为非官话；M5 = M0 + 相邻 + 经济大区 + 同一方言区。
- 每个模型报告：关键哑变量的系数与稳健标准误、相对 M0 的离差下降比例、留一迁出省的样本外离差下降比例（留出省的迁出固定效应按其实际迁出总量校准，同 T20）。
- 稳健性两项：去掉 mixed=是 的省份（作迁出或迁入均去掉）后重估 M3、M5；去掉北京、上海、广东作为迁入地的省对后重估 M5。子样本各自估 M0 作基准。
- 坐标、方言归属、经济大区、相邻全部用仓库现有文件（`data/raw/capital_coords.csv`、`data/partitions/province_dialect.csv`、`province_econ_region.csv`、`province_adjacency.csv`），不重抓、不改动。
- 固定种子同 T20。

## 唯一变化

迁移年份：用 2010 年人口普查“按现住地和五年前常住地分的人口”省对省表（2005→2010）。表号与口径（长表抽样或全口径、五年前常住地的定义）现场核实后记入 `data/raw/SOURCES.md`。

## 实现

- `scripts/t22_gravity_2010.py`：复用 `t20_gravity.py` 的函数，只换迁移输入文件；一条命令重算。
- 输出 `outputs/t22_results.csv`（列同 `t20_results.csv`，另加 `year`），以及 `outputs/t22_vs_t20.csv`（每个样本×模型两年的系数、SE、离差下降比例并排）。
- 若原表是图片：沿用 T20 的转录与校验（行合计、列合计全部闭合，另目视抽查 5 格），任何一格未闭合即在报告列出，不估算补齐。
