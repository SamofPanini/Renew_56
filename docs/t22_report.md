# T22 报告｜V-08 对照：2005→2010 与 2015→2020 的同一套引力模型

计划：`docs/t22_plan.md`（0f980e6，读数据前提交）。脚本：`python scripts/t22_gravity_2010.py`。结果：`outputs/t22_results.csv`，两年并排：`outputs/t22_vs_t20.csv`。

## 数据与口径

- **2010 年**：《中国2010年人口普查资料》第二部分（长表数据资料）表 7-8“全国按现住地和五年前常住地分的人口”。国家统计局网站给的是 Excel 导出的 HTML 表（`data/raw/census2010_migration_5yr_table7-8.htm`），直接解析，31 行与 35 列的合计全部闭合，另从原 HTML 重取 5 格核对一致。流量为五年前（2005-11-01）常住 i 省、现住 j 省的人数，930 个省对都有数。
- **口径**：两年都是长表抽样登记数（细则或方案都写抽 10% 的户），不是全口径。五年前常住地都按时点前五年的 11 月 1 日零时计。2010 年只登记到省，2020 年对县外的人登记到地址；汇总到省级后，两年的省对定义相同。原句见 `data/raw/SOURCES.md`。
- 距离、相邻、经济大区、方言归属与 T20 是同一批文件，模型、样本与稳健性都由同一函数（`t20_gravity.run_all`）计算，唯一变化是迁移表。

## 能说什么

- 在本口径下，8 个模型里关键变量的系数方向两年全部一致：相邻为正，同经济大区、同方言区、同为官话或非官话为负；两项稳健性在两年里都没有改变方言区系数的方向。
- 在本口径下，单独加入“同一方言区”，2010 年离差下降 2.5%，2020 年 4.6%；“同一经济大区”分别为 11.3% 与 18.4%；“相邻”分别为 2.0% 与 1.0%。两年都是经济大区解释的离差多于方言区。

## 不能说什么

- **不是趋势**。两年各估各的，没有做面板，也没有检验系数差异。两年的离差下降比例差多少，不能读成“方言或大区的作用在变强或变弱”。
- **口径只在省级相同**。两年都是 10% 长表抽样，但实际入样比例、登记方式（2010 年只登记到省，2020 年对县外的人登记到地址）、各年的漏报与样本误差都没有核对，数字不能当成全口径人数直接比较。
- 方言归属是同一份粗归类（中文维基，等级 D），8 省留空，18 省跨区，两年用的是同一套省份标签。
- 是省级汇总的相关关系，不是因果；负系数不表示方言相同使人不迁移；方言区与地形、历史、经济联系高度重合。
- 不能推到个人或任何人群。
