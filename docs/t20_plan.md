## 模型与比较

- 观测单位：有向省对 (i→j)，i≠j，约 930 个。结果变量：五年间由 i 迁到 j 的人数。
- 基线模型 M0：泊松伪极大似然引力模型，含迁出省与迁入省固定效应，加省会间球面距离的对数。
- 依次各加一个“同组”哑变量，分别估计：
  - M1 地理相邻
  - M2 同一统计局经济大区（东部、中部、西部、东北）
  - M3 同一方言区（十区）
  - M4 同为官话或同为非官话（二分）
  - M5 = M0 + 相邻 + 经济大区 + 同一方言区（看方言区在控制前两者后还剩多少）
- 每个模型报告：该哑变量的系数与稳健标准误、相对 M0 的离差下降比例、留一迁出省的样本外离差。
- 稳健性两项：去掉 mixed=是 的省份后重估 M3、M5；去掉北京、上海、广东作为迁入地的省对后重估 M5。
- 用 Python（pandas、statsmodels）。随机性只出现在留一划分，固定种子。
